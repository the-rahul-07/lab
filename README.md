# 🎓 Second Year Engineering Lab Programs

A collection of practical programs and lab assignments completed during **Second Year of Engineering**.

This repository contains programs for **Data Structures (DS)** and **Object-Oriented Programming and Computer Graphics (OOPCG)**, written in **C++ Python and java **. The aim is to keep practical codes organised in one place for learning, practice, and lab exam revision.

---

## 📚 Subjects

### 🔹 Data Structures (DS)

Programs covering fundamental data structures, algorithms, and problem-solving techniques.

**Topics include:**
- Arrays and Strings
- Searching and Sorting Algorithms
- Linked Lists
- Stacks and Queues
- Trees and Binary Search Trees
- Graph Traversals — BFS and DFS
- Hashing Techniques
- Algorithm Analysis and Complexity

### 🔹 Object-Oriented Programming and Computer Graphics (OOPCG)

Practical implementations of object-oriented programming concepts and computer graphics algorithms.

**Topics include:**
- Classes and Objects
- Constructors and Destructors
- Inheritance and Polymorphism
- Encapsulation and Abstraction
- Operator Overloading
- Line and Circle Drawing Algorithms
- 2D Transformations
- Clipping Algorithms

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the required subject and programming-language folder.

3. Run the program using the appropriate compiler or interpreter.

**For C++:**
```bash
g++ filename.cpp -o program
./program
```

**For Python:**
```bash
python filename.py
```

On Windows, run the compiled C++ program using `program.exe`.
